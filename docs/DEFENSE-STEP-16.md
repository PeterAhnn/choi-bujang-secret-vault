## 원문과 계약 대조

화면에서 직접 추출한 전체 원문은 DEFENSE-STEP-16-PROMPTS.md에 보관한다. 채팅에 상세 프롬프트 전체를 먼저 제시했다. 옮겨 적은 문장부호 한 곳은 즉시 정확한 문장으로 바로잡았으며 보관 원문은 화면 그대로다.

renderStatus 입력은 { devices, sessions, notifications, diagnostics, mode }다. 제공 화면이 resource의 snapshot을 전달한다. diagnostics 최초 상태는 idle, 제공 도움정보 불러오기가 loading 및 ok/error를 전달한다. trackError와 renderMode가 학생 상태를 다시 그린다. 학생 함수에서는 직접 조회하지 않는다. 상단 다시 불러오기는 기기·세션 등을 갱신하고 진단 조회는 별도 제공 버튼을 사용한다.

이번 수정은 renderStatus 구현과 renderEvents의 showDetail 안 미지원 안내로 한정한다. 나머지 13~15단계 기능·제공 코드·인증·판정 코드를 보존한다.
