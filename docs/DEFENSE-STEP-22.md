## 범위와 버전

기준 커밋은 `a3c66e394502c517b722d67ff68b1b4094a4528e`이며 저장소는 PeterAhnn/choi-bujang-secret-vault, 브랜치는 main이다. 학생 버전은 **검증 중 r22.1**, 제공 시작 틀은 0.2.21이다. 13~21단계 앱 코드·제공 파일·의존성·Git 기록·기존 사용자 사본을 보존하고 인수인계 문서와 재현 근거만 추가한다.

## 작성·실행한 내용

- [인수인계 문서](STUDENT_HANDOFF.md)에 커밋 고정, 상대 경로 실행, 과거 단계별 공식 검토 이력, 이번 재현, 데이터 보존·백업·복원 계획과 미확인 범위를 구분했다. 21단계 설명서의 실행 명령도 저장소 기준 상대 경로로 보완했다.
- 기존 프로젝트 밖의 새 폴더에 GitHub main을 clone한 뒤 기준 커밋을 detached checkout했다. 인증 파일·.env·개인 보관소·node_modules는 복사하지 않았다.
- Node.js 24.21.0, Windows PowerShell 5.1.26100.9711, Windows 11 Pro 64비트에서 npm run check와 20단계 합성 표시 계약·앞 단계 원문 보존 검사 68개를 통과했다. 합성 제공 요청 5회, 실제 외부 통신 0회인 검사를 13~21 전 기능 재시험이나 실운영 결과로 쓰지 않는다. 하네스 비교 기준 a5b77e0과 실제 복제 원천 a3c66e3을 구분했다.
- 공식 실행 도구를 Demo·5195·Background로 시작해 HTTP 200과 예제 표시를 확인했다. 해당 node 16340만 종료해 포트가 닫힌 뒤 같은 명령으로 재실행했다. 원래 5189와 사용자 확인용 5193 앱은 유지했다.
- 새 복제본의 보호 현황, 학습 자료실 예제 허용, 사건 상세, 진단 표시와 OSV not_configured를 확인했다. 실제 AI·SDP·보안 조치·OSV 외부 성공·전체 DB 복원은 실행하지 않았다.
- 기준 복제본의 CRLF checkout 차이는 Git blob과 정규화 내용 일치로 확인했다. 원래 학생 소스 SHA256은 보존했다. 최종 제출 전에는 줄바꿈 변환을 끈 새 복제본에서 제출 커밋의 원문과 실행을 추가 확인한다.

## 직접 확인과 제출 상태

사용자는 원래 폴더와 기록이 그대로 남아 있다고 직접 확인했다. 실행 코드·의존성 변경 0개, 과거 단계 근거 문서 9개와 사용자 미추적 사본 26개 보존을 별도로 확인했다. 검증 중 버전·미완료 범위 구분도 직접 확인했다. 두 응답은 runtime-reproduction.json에 구분해 기록했다.

공식 제출은 아직 하지 않았다. 문서의 같은 런타임 원문과 최종 제출 커밋을 연결해 확인한 뒤 제출한다. 공식 원문 검토는 새 환경에서 서버가 실행하는 검증과 다르며, 접수 뒤 최대 5분까지만 판정을 확인한다.
