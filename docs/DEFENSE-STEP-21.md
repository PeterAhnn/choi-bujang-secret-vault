## 검증 상태

공식 실행 도구를 Demo·5194·Background로 실행해 HTTP 200과 시작 문구를 확인했다. 해당 node 프로세스 16688만 종료하고 포트가 닫혔음을 확인한 뒤 같은 명령으로 재실행했다. 새 프로세스 8932의 브라우저 화면에서 세 메뉴·예제 자료·연습 사용자·연습 PC를 확인했다. 사전 검사 서버는 종료했고 기존 5189 앱은 유지했다. 실제 계정 연결·AI 요청·보안 조치는 실행하지 않았다.

독립 검토자는 공식 여섯 문서 기준과 제공 코드를 읽기 전용으로 대조했고 불일치를 발견하지 못했다. 실행을 독립 수행했다고 기록하지 않는다. 근거는 verification/stage21/runtime-check.json에 보관한다.

사용자는 공식 직접 확인 1에 따라 새 PowerShell 창에서 예제 앱의 실행·종료·재실행을 확인했다고 응답했다. 사용자 확인용 5193 포트와 기존 5189 포트가 함께 열려 있는 것도 확인했다. 직접 확인 2에서는 경로·명령·메뉴·버튼 이름이 일치한다고 확인했다. 두 응답을 runtime-check.json에 기록했다. 이번 단계 문서만 커밋·push하고 공식 코드 검토에 제출한다. 접수 뒤 판정 대기는 최대 5분이며 통과한 제출은 반복하지 않는다.
