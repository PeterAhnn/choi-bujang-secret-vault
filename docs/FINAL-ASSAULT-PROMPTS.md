구성: 관제 대시보드형·포장 없이 프로젝트 폴더에서 실행. 아래 내용은 작전 확정 뒤 포털의 pre 요소에서 직접 읽었다.

## 1일차 · 22단계 프로젝트를 다시 실행하고 핵심 기능 3가지를 고릅니다

```text
내 앱(나라찬) 프로젝트를 22단계까지 만든 그 폴더에서 다시 실행하고 싶어. 먼저 실행 방법을 확인해서 알려 주고, 지금 화면에서 실제로 동작하는 기능과 아직 동작하지 않는 기능을 표로 나눠 줘. 그다음 권장 제작 기간에 다듬을 핵심 기능 3가지를 고르는 걸 도와줘.
내 작전은 화면 틀 관제 대시보드형(맨 위 상태 카드 네 개, 아래 추이와 기록), 포장 형태 포장 없이 프로젝트 폴더에서 실행(포장 명령은 실행하지 않음)로 정했어. 이 틀과 포장 형태에 맞춰 진행해 줘.
기존 프로젝트 폴더와 이미 낸 제출물은 지우거나 옮기지 말고 그대로 둬.
고치기 전에 수정할 파일 목록과 이유를 먼저 보여 주고, 내가 확인한 다음에 고쳐.
내 PC에서 실제로 잰 값과 예시 값(실제 조회 결과가 아닌 설명용 값)은 화면과 설명에서 따로 표시해 구별해 줘.
끝나면 내가 같은 결과를 다시 만들 수 있게 실행 명령과 확인 순서를 적어 줘.
```
