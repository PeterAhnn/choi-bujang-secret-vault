## 원문과 계약 대조

원문은 DEFENSE-STEP-14-PROMPTS.md에 화면 그대로 보관한다. 채팅에도 상세 프롬프트 전체를 먼저 표시했다. 로컬 STUDENT_PROMPTS.md의 이전 확인 안내는 네 판정 실제 재현·서버 중지를 요구하지만, 최신 포털은 실제 반환 결과만 확인하고 네 판정을 만들기 위해 정책·인증을 바꾸지 않도록 안내한다. 최신 포털을 따른다. 상태별 분기는 별도 모의 입력으로 검사한다.

시작 당시 renderDecision은 대기 문자열만 반환했다. 제공 app.js의 studentData('decision')가 snapshot(state.access)와 appId를 전달한다. 제공 버튼이 /api/access로 요청한 뒤 loading 및 ok/error 상태에서 학생 함수를 다시 호출한다. renderStudent가 반환 DOM으로 이전 표시를 교체한다. 학생 함수에서는 새 요청을 만들지 않는다.
