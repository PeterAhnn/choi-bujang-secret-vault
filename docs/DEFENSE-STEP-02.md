### 원문의 수량 불일치

제작 1은 "가상 메모 세 개", 제작 2는 "같은 가상 메모 네 건"이라고 적혀 있다. 원본은 네 건이며 화면 확인도 네 카드이므로 **네 건 보존**을 구현 기준으로 삼는다. 이 해석은 AI의 구현 판단이며 원문 수정으로 표현하지 않는다.

### 제출·가점

기본 조건 모두 통과 70점, 다음 각 10점(모두 충족하면 100점):

1. `/data.json` 404 또는 메모 0건.
2. 배포 `/aleph.json` 정상 응답. 빌드 자동 생성을 보존.
3. 첫 화면의 `X-Content-Type-Options: nosniff` 또는 `Content-Security-Policy` 헤더.

실제 제출 화면은 배포 주소와 선택 설명만 받는다. `npm run bundle`은 2단계 팝업에 명시된 제출 전 점검이며 1단계 조건이 아니다. 추가 보고서나 AI 과제 제출 형식을 필수로 요구하지 않는다.

### 문제 확인·되돌리기

기대 결과, 실제 화면, 첫 오류, 이번 변경 파일을 모아 원인 후보 2~3개 중 가장 가능성 높은 하나만 최소 수정한다. 되돌리기는 `git status`·`git diff`로 다른 변경과 DB 자료를 구분하고, 사라질 내용을 보여준 뒤 사용자 확인을 받아 이번 단계 파일만 복구한다. `reset --hard` 금지.
