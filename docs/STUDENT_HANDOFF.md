## 2. 새 빈 폴더에서 받기

기존 프로젝트 밖의 원하는 부모 폴더에서 PowerShell을 엽니다. 아래 대상 폴더가 이미 있으면 이름을 새로 정합니다. 기존 폴더를 지우거나 덮어쓰지 않습니다. 확인할 40자리 커밋은 포털 제출값이나 인수인계 때 전달받은 값을 사용합니다. 비밀값이 아닙니다.

```powershell
git clone --no-checkout --config core.autocrlf=false https://github.com/PeterAhnn/choi-bujang-secret-vault.git .\narachan-r22-repro
Set-Location -LiteralPath '.\narachan-r22-repro'
$reproductionCommit = Read-Host '확인할 40자리 커밋'
if ($reproductionCommit -cnotmatch '^[0-9a-f]{40}$') { throw '40자리 소문자 커밋을 확인하세요.' }
git checkout --detach $reproductionCommit
if ($LASTEXITCODE -ne 0) { throw '커밋을 가져오지 못했습니다.' }
git rev-parse HEAD
git status --short
```

출력된 HEAD가 입력한 값과 같은지 확인합니다. `core.autocrlf=false`는 새 복제본의 줄바꿈 변환만 제어합니다. 원래 저장소 설정은 변경하지 않습니다. clone에는 추적된 코드와 문서만 들어오며, 제외된 설정·자격·실제 DB·사용자 미추적 사본은 복사되지 않습니다.

## 3. 실행·종료·재실행

21단계 [학생 실행 설명서](STUDENT_RUNBOOK.md)를 따릅니다. 저장소 최상위에서 아래 순서로 실행합니다. 5195가 사용 중이면 기존 프로그램은 유지하고 다른 빈 포트와 같은 브라우저 주소를 사용합니다.

```powershell
Set-Location -LiteralPath '.\on-client'
node --version
npm run check
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1 -Demo -Port 5195
```

로컬 앱에는 추가 npm 의존성이 없어 `npm install`을 요구하지 않습니다. 저장소 루트의 package-lock.json은 웹 자료실용이며 로컬 앱 자체의 잠금 파일이 아닙니다.

1. `케셰브가 켜졌습니다`와 `서버가 응답한 것만 확인했습니다` 안내가 보이면 `http://127.0.0.1:5195/`를 엽니다.
2. 보호 현황에서 예제 자료·연습 사용자·연습 PC를 확인합니다. 업무 앱에서 학습 자료실 접속 요청의 예제 허용 판정을 봅니다. 보안 기록에서 예제 사건과 상세를 확인합니다.
3. 이 PowerShell에서 Ctrl+C로 종료하고 해당 포트가 응답하지 않는지 확인합니다. 같은 명령으로 재실행하고 브라우저를 새로고침합니다.

AI 사전 검증에서는 같은 공식 명령 끝에 `-Background`를 붙였습니다. 종료 시 실행 도구가 출력한 해당 node 프로세스만 확인해 종료했습니다. 원래 앱의 5189 포트와 사용자 확인용 5193 포트는 종료하지 않았습니다. 계정 연결용 보관소·인증서·기존 .env를 새 폴더로 복사하지 않았고, 실제 AI 호출·보안 조치는 요청하지 않았습니다.

## 7. 남은 범위와 인수 조건

- 버전은 검증 중 r22.1입니다. 실제 SDP 원천 연결·사건 설명·조치 집행·효과 관측·결과 재조회·외부 OSV 성공과 전체 DB 재해 복원은 미확인입니다.
- 코드는 원래 저장소와 새 복제본에서 대조합니다. 새 문제를 고치면 새 커밋을 만들고 해당 커밋의 재현 기록을 다시 확인합니다.
- AI가 수행한 명령, 사용자가 직접 확인한 내용, 합성 데이터, 공식 원문 검토 결과를 각각 기록합니다. 사용자 대신 실행한 명령을 사용자가 직접 실행했다고 쓰지 않습니다.
- 기존 폴더·자료·기록은 보존합니다. 22단계 제출 뒤 최대 5분까지만 판정을 확인하며 통과한 제출은 다시 제출하지 않습니다.
- 사용자는 기존 폴더·기록 보존과 검증 중 버전·미완료 범위 구분을 각각 직접 확인했습니다. 새 복제본의 명령 실행 주체는 AI이며 사용자 직접 실행으로 소급하지 않습니다.
