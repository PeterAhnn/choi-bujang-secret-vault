# XDR-03 실제 진행 기록

출처: https://aleph-omega.vercel.app/defense 보너스 작전 「알려진 취약점 악용을 잡아 냅니다」. 확인일:2026-10-13. 표시 배점120점과 심판100점 척도를 구분합니다.

최 부장 PC의 오래된 로그 라이브러리로 들어오는 알려진 취약점 요청을 판단합니다. 실제 취약점 공격을 전송하지 않고 제공 가상 경보를 읽습니다. 기본 판정기 규칙을 보존합니다.

순서: 이어받기 읽기 전용 확인 → 제작1 안전한5필드 추출24/24 → 제작2 근거가 있는 패턴2개 → 제작3 단일파일 순수decide → 제작4 만료/근거 있는 차단규칙과 최소로그 → 제작5 공식 runner 실행 → 제출전 runner 재실행과 저장점.

근거: CVE-2021-44228 형태 요청과 MITRE ATT&CK T1190(https://attack.mitre.org/techniques/T1190/). 완전한 원격JNDI 조회는 block, 단어/문서/불완전 점검은 alert, 정상은 record입니다. 공격 페이로드를 실행하거나 원문을 로그에 쓰지 않습니다.

실제 로컬 결과: block8·alert8·record8, 정상 차단0. 단독data모듈 로딩 성공, import 없음, 연결부 가상 공격deny·정상allow·만료후allow. 규칙8개에 경보ID·만료15분을 붙였습니다. 이 연결부 가상 검사는 운영 엔진 연결 증거가 아닙니다. 공식 심판은 아직 미완료입니다. 원본경보와 기존 판정기를 변경하지 않았습니다.

최신 공식 결과: 4a0bb635d6787ee5f181b5a97e9529af9aec4fe2의 첫 제출 공식100/100점·방어 성공, 조건4개·완결성 가점3개를 확인했습니다. 위 미완료 문구는 제출 당시 기록입니다.
