현재 워크벤치의 ‘포털 제출 준비’는 13~20단계를 지원합니다. 21·22단계에서는 과제 화면에 저장소 주소와 40자리 커밋을 직접 입력합니다. 비공개 저장소를 공개로 바꿀 필요는 없습니다.
비공개 커밋은 해당 단계의 ‘비공개 저장소 원문 준비 방법’을 펼쳐 ‘원문 전달 도구 받기’를 누릅니다. ZIP을 프로젝트 밖에 압축 해제하고, JSON을 저장할 프로젝트 밖의 새 폴더도 미리 만듭니다.
제출할 프로젝트의 Git 최상위 폴더에서 PowerShell을 열고 안내된 student-source-cli.mjs 명령을 실행합니다. 도구·출력 파일 경로를 본인 PC에 맞게 바꾸고 --commit 뒤에 제출할 40자리 커밋을 지정합니다. 도구는 커밋된 원문만 묶으며 학생 코드를 실행하거나 업로드하지 않습니다.
생성된 JSON을 같은 단계의 ‘비공개 저장소 원문 묶음’에서 선택합니다. 저장소·커밋·단계를 다시 확인한 뒤 제출합니다. 원문 전달 완료와 AI 검토 통과는 다르므로 서버 상태와 판정 설명을 확인합니다. 원문 전달만 실패하면 기존 접수를 유지하고 ‘원문만 다시 보내기’를 사용합니다.
