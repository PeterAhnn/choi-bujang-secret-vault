# 나라찬 · 세 기능 시연

학생 버전: **검증 중 r22.2**. Windows에서 프로젝트 폴더의 공식 실행 도구로 켠다. [실행 안내](FINAL-ASSAULT-RUN.md)를 사용하며 포장 명령이나 설치 프로그램은 실행하지 않는다.

## 시연 순서

1. **보호 현황**의 **나라찬 · PC 관제 대시보드**에서 **PC 상태 다시 조회**를 누른다. CPU·메모리·앱 디스크 여유와 실제 조회·local-pc·측정 시각·단위를 확인한다.
2. 방화벽 세 프로필과 네트워크 구성 수를 확인한다. PC 조회와 SDP 연결 상태가 따로 표시되는지 본다.
3. Windows 기록의 최근 24시간 경고·오류, 최대 5,000건과 생략 여부를 확인한다. 다시 수동 조회해 아래 **최근 수동 조회**에서 시각별 값을 비교한다.

조회 중 **PC 조회 취소**를 누르면 현재 값은 지우고 늦은 결과를 무시한다. 이는 공유 GET 자체의 취소가 아니다. 원래 요청이 끝난 뒤 수동 재조회로 복구한다. 실패·부분 실패·정상 0값·지연 응답의 나머지 분기는 별도 합성 검사이며 실제 장애를 만들었다고 기록하지 않는다.

## 제공 기능과 학생 개선

| 제공 기능 | 학생이 개선한 부분 |
|---|---|
| Node.js·Windows 읽기 전용 PC 수집기와 고정 GET 경로 | 네 카드와 요약, 시각·단위·출처·오류 설명 |
| 검증된 공통 UI·통신·기존 단계 표시 계약 | 최근 수동 조회 10개 비교, 현재 값과 과거 이력 구분 |
| 공식 꾸밈 스키마와 적용기 | 나라찬 이름·허용 색·학생 영역 우선 배치 |

## 남은 한계

- PC 조회는 누를 때의 관찰이다. 자동 감시·침해 판정·치료·설정 변경 기능이 아니다.
- CPU는 약 200ms 표본이며 다른 도구와 측정 시점·집계 범위가 다를 수 있다. 디스크는 앱이 있는 볼륨만 읽는다.
- Windows 기록은 두 로그의 최근 24시간·최대 5,000건이다. PC 전체 기록이나 공격 탐지 결과가 아니다.
- 최근 10개 이력은 메모리에만 남으며 브라우저 새로고침 후 복원되지 않는다.
- 실제 SDP 원천·AI 사건 설명·조치 집행·효과 관측·외부 OSV 성공·전체 DB 복원은 미확인이다. 13~22단계 공식 원문 검토와 구분한다.
- 다른 사람의 첫 사용 관찰은 미실시다. 본인 화면 확인과 AI의 별도 폴더 재현으로 바꿔 적지 않는다.
