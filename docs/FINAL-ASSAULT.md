## 제공 기능과 학생 개선

제공 서버·PC 수집기·인증·기존 통신 경로는 바꾸지 않았다. 학생 파일의 createStudentView가 제공 api를 받아 정확한 GET /api/pc/status를 수동 호출한다. 기존 7개 표시 함수의 원문은 그대로이며 renderStatus 앞에 지속되는 PC 패널을 붙였다. 8개 표시 함수의 기존 입력에 대한 출력도 PC 패널을 제외하고 기준 버전과 대조한다.

학생 개선은 네 자원·방화벽 카드, 네트워크·Windows 기록 요약, 실제 출처·시각·단위·부분 실패 설명, 최근 수동 조회 10개 비교와 화면 취소·복구다. PC 조회를 위해 다른 학생 영역을 다시 그리는 onChange를 호출하지 않으므로 기록 필터·선택을 건드리지 않는다. 꾸밈은 공식 appearance.json 계약의 앱 이름·세 색·student-first 배치만 사용한다.

## 2~4일차 확인

- 실제 기존 앱에서 두 번의 수동 조회와 시각별 자원 이력을 확인했다. CPU 약 200ms 구간과 GiB 단위를 명시했다. 작업 관리자 표시는 가까운 시각의 참고 비교이며 CPU·메모리의 정확한 동시 일치 검증으로 적지 않는다. 디스크는 앱이 위치한 볼륨의 범위다.
- 네트워크 구성 수, 방화벽 세 프로필, 최근 24시간 Windows 기록 집계와 최대 5,000건 범위를 실제 화면에서 확인했다. SDP 미연결은 별도로 표시됐다.
- 실제 키보드 Enter로 조회·화면 취소를 실행했다. 공유 요청이 끝난 뒤에도 취소 상태가 유지됐고 수동 재조회로 복구됐다. 서버 GET 자체를 취소한 것으로 쓰지 않는다.
- 모의 검사는 실제 조회·공식 판정과 별도다. 중복 전송·지연 응답·부분 실패·정상 0·오류·최근 이력·기존 표시 회귀를 확인한다. 최종 검사 결과와 원문 해시는 verification/final-assault/mock-check.json에 남긴다.

## 5일차 실행 안내

다른 사람이 처음 사용하다 막힌 기록은 아직 없으며 꾸며 적지 않았다. 공식 안내의 다른 폴더 방법을 참고해 AI가 사전 재현했다. 기준 687120e의 새 복제본에 현재 학생 파일과 문서를 대조 복사한 결과이며 최종 커밋의 재현과 구분한다. 원래 폴더·사용자 사본·개인 인증 자료를 보존했다. 재현 앱 5197에서 문법 검사·실제 PC 조회·종료·포트 닫힘·같은 공식 도구 재실행을 확인했다.

사용자는 실행 안내 2절에 따라 자원·네트워크/방화벽·Windows 기록 확인과 재조회 이력 비교를 직접 수행하고 **“안내만으로 따라갔고 막힘이 없습니다”**라고 확인했다. 이는 본인의 화면 사용성 확인이다. PowerShell 기동·종료·재실행을 사용자가 수행했다고 기록하지 않으며, 다른 사람의 첫 사용 관찰은 미실시로 남긴다.

## 1일차 · 기존 앱과 핵심 기능

기존 5189 앱이 원래 폴더에서 실행 중임을 확인했다. 제공된 내 PC 상태 화면에서 CPU·메모리·앱 디스크 여유·네트워크 구성·방화벽 세 프로필·Windows 기록 집계가 표시됐다. 이 조회 기능은 제공 코드이며 이번에 학생이 만든 성취로 쓰지 않는다. SDP 신원·기기·세션은 연결 없음으로 표시되며 PC 실측과 별도다.

| 핵심 기능 | 제공 기능과 현재 범위 | 이번에 개선할 부분 |
|---|---|---|
| PC 자원 상태 | CPU·메모리·앱이 위치한 디스크를 읽는 제공 수집기와 카드가 있다. | 시각·출처·단위를 붙인 학생 요약과 최근 수동 조회 비교를 만든다. |
| 네트워크·방화벽 | 주소를 가린 로컬 구성 수와 Domain·Private·Public 설정을 읽는다. | 인터넷 성공이나 SDP 허용과 구분하고 항목별 확인 불가·이유를 표시한다. |
| Windows 기록 요약 | 최근 24시간 System·Application의 경고·오류를 최대 5,000건까지 집계한다. | 기간·상한·잘림 여부와 건수의 의미를 학생 화면에 표시한다. 침해 판정으로 쓰지 않는다. |

기존 통과 코드의 AI 연결·설명·조치·OSV 표시 기능은 보존한다. 실제 SDP 원천·조치 집행·OSV 외부 성공·전체 DB 복원은 기존 미확인 범위로 유지한다.
